    How to build a conversation
    1. Tap a step to see that moment in the picture. New conversation… at the top starts a fresh one with your two characters.
    2. The buttons under each character add what happens next: Says… (a line), Smile, Bop, Move, Leave. New steps go right after the selected one.
    3. Type a line, press Enter, and the other person's next line starts.
    4. + between steps (or + Add step) slips in music, sounds, pauses, backgrounds anywhere.
    5. + → Branch adds a player choice or an “if… otherwise…” (e.g. Yuel is female). Each path gets its own lane; fill it with +. Drag ⇆ on Rejoin to say where the paths meet again. Preview as under the picture picks which path plays.
    6. Code → Copy gives you the event code for LT-Maker.

    On a keyboard: ↑ ↓ move through steps, Enter edits, Del deletes, Space plays.

    Project assets

    Pick the folder that ends in .ltproj (for example Bizarre Adventure.ltproj). The preview then uses that project's characters, portraits, backgrounds, music, sounds, fonts and voices. Everything is read inside your browser; nothing is uploaded, even if the browser's prompt says "upload". Add new art or music to the project, then reopen or reload the folder here to see it.

    Inside an embed (like Notion) the browser can't remember the folder, so you'll pick it once per visit. Opened as its own tab in Chrome or Edge, it reopens with one click.

    Keyboard shortcuts

    Moving around
    ↑ ↓ (or K J)Previous / next step (also ← → in the timeline layout)
    Home EndFirst / last step
    Enter or EEdit the selected step (jumps into its first field)
    EscLeave a text field (so the arrows work again) · stop playback
    Changing steps
    LAdd a line after the selected step (the next speaker)
    A or +Add any step after the selected one (opens the list)
    Del / BackspaceDelete the selected step
    Ctrl+DDuplicate the selected step
    Alt+↑ ↓Move the step earlier / later (also drag its ⠿ handle)
    Ctrl+Z · Ctrl+YUndo · redo (Ctrl+Shift+Z also redoes)
    Writing a line
    EnterFinish the line and start the other person's next line
    Shift+EnterNew line inside the same box (waits for a click in game)
    Preview
    SpacePlay from the selected step · advance while playing
    P · Shift+PPlay from the selected step · from the top

    TSwitch between timeline and column layout
